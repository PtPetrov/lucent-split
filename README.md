# Lucent Split

A lightweight Lucent distribution calculator for **Throne and Liberty** guild parties.

## Features

- Calculates distributable Lucent after Auction House tax and seal cost
- Supports parties of 2–6 people
- Shows the individual share
- Calculates guild-sale amounts for buyers inside or outside the party
- Responsive single-page interface

## Run locally

Open `dist/index.html` in a browser. No installation or build step is required.
